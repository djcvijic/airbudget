# airbudget

A single-page, no-build-step web app. Pure HTML/CSS/JS — no framework, no
bundler, no package manager.

- `index.html` — page structure and screens.
- `theme.css` / `theme.js` — generic page theme and behavior (fonts, colors, buttons, back-to-top).
- `main.css` / `main.js` — app-specific styling and logic.

## Running it

```bash
python3 -m http.server 8935
# then open http://localhost:8935/index.html
```
